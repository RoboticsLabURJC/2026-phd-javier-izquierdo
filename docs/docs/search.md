Parte de STEM como base: Science, Technology, Engineering and Mathematics

Se combinan junto con STEM, coding, computer thinking and engineering skills en proyectos. Para esto sirve la robótica educativa

La robótica educativa provee de opciones para los estudiantes de como funciona la tecnología en el mundo real, y promover el pensamiento crítico

También permite introducir otras disciplinas relacionadas como literacy, social studies, dance, music and art, además del trabajo colaborativo

Computational thinking

use of robots can increase student motivation and encourage persistence when students encounter challenging and complex learning scenarios

Suele ocurrir computational thinking en clases prácticas, no teóricas

Falta de curricular resources para la enseñanza apropiada para la edad. Y la mayoría de estos son focus on programming the robot rather than presenting an environment for applying subject-specific knowledge

## Competencias básicas:

- Programación: C -> C++, Python
- Matemáticas: Álgebra, Cálculo, Estadística, (Optimización)
- Física: nivel básico
- Ingeniería de control: 
- Ingeniería electrónica: diseño de circuitos

### Competencias Robóticas

- Sensores
- Actuadores
- Aplicación programación + física: Ingeniería de simulación
- Robótica movil
- HRI
- Aplicaticón control + robótica: Robótica industrial
- Robótica de servicios
- Manipulación robótica

### Software exclusivo

- Redes y comunicaciones
- Aplicación programación + matemáticas: Inteligencia Artificial
- Aplicación programación + matemáticas + sensor(cámara): Vision artificial

### Hardware exclusivo (Mecatrónica)

- Fluidos
- Materiales
- Termodinámica
